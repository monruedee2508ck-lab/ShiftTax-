# ShiftTax

**Your Shifts. Your Income. Your Balance.**

*Smart Tax Solutions for Growth* — เว็บแอปสำหรับพยาบาล: ลงตารางเวร คิดค่าเวร/OT อัตโนมัติ บันทึกรายรับรายจ่าย วางแผนภาษี ปลดหนี้ และเก็บหน่วยกิต CNEU

## ฟีเจอร์
- **ตารางเวร** — ลงเวร ช / บ / ด / เวรนอก / OT / ลา / พักร้อน / ประชุม / อบรม, ปุ่มเวรควบ, ลงหลายวัน, แชร์ตารางเวรเป็นรูปหรือข้อความ
- **การเงิน** — บันทึกรายรับรายจ่ายตามหมวด (แบบ Happy Money), งบประมาณรายเดือน, สุขภาพการเงิน, สินทรัพย์และหนี้สิน
- **เป้าหมายปลดหนี้** — ดอกเบี้ย ค่างวด วันครบกำหนด, จำลองการโปะแบบก้อนเล็กก่อน / ดอกเบี้ยสูงก่อน
- **ภาษี** — ภาษีเงินได้บุคคลธรรมดา 40(1) / 40(2), ค่าลดหย่อน, คำแนะนำซื้อ RMF / Thai ESG / ประกัน แบบเจาะจงตัวเลข, ขั้นบันไดภาษี
- **CNEU** — บันทึกการอบรม/ประชุม พร้อมแถบความคืบหน้า 50 หน่วย / 5 ปี
- **การแจ้งเตือน** — เวรวันนี้/พรุ่งนี้, พักระหว่างเวรไม่พอ, ทำงานติดกันหลายวัน, หนี้ใกล้ครบกำหนด, CNEU ใกล้หมดอายุ

## การใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร (ไฟล์เดียว รวมรูปและโค้ดไว้ในตัว)

**เผยแพร่ด้วย GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save แล้วเปิดที่ `https://<username>.github.io/<repo>/`

## ข้อมูล
ข้อมูลทั้งหมดเก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่องเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์
